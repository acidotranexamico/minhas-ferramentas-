# minhas-ferramentas-

## Ferramentas

### humanizer

Cópia do repositório [blader/humanizer](https://github.com/blader/humanizer) (v3.1.0, licença MIT), uma skill que reescreve textos com cara de IA para que soem escritos por uma pessoa, sem mudar o conteúdo.

- `humanizer/`: repositório original completo (sem o histórico git).
- `.claude/skills/humanizer/SKILL.md`: a mesma skill instalada para o Claude Code neste projeto.

Como usar no Claude Code, dentro deste repositório:

```
/humanizer

[cole seu texto aqui]
```

Ou peça em linguagem natural: "Humanize este texto: ...". Para reescrever um arquivo, passe o caminho dele.

Para usar no Claude.ai ou no Claude Desktop, compacte a pasta `humanizer/` em ZIP e envie como skill em Configurações.

Observação: os exemplos da skill estão em inglês, mas ela também funciona com textos em português.
